# 🍴 Empadão da Taí

Aplicativo desenvolvido para facilitar pedidos do **Empadão da Taí**, unindo sabor caseiro e tecnologia.  
O projeto permite que clientes escolham sabor, tamanho e combos, com integração direta ao **WhatsApp** para envio automático do pedido.

---

## 🚀 Tecnologias utilizadas

- **React Native** — interface moderna e responsiva  
- **Expo Router** — navegação simplificada  
- **Firebase** — armazenamento e autenticação  
- **WhatsApp API (wa.me)** — envio direto do pedido  
- **EAS Build** — geração de app para iOS e Android  
- **Vercel** — deploy da versão web para testes

---

## 💡 Funcionalidades

- Formulário de pedido com sabor, tamanho e observações  
- Envio automático para o WhatsApp da Taí  
- Registro dos pedidos no Firebase  
- Interface adaptada para web e mobile  
- Ícone e identidade visual personalizados
